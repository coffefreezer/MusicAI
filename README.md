# 🎵 MusicAI - Personalized Music Recommendation Web App

MusicAI is an intelligent web application designed to deliver personalized music recommendations by integrating with the Spotify API. Built with a Python Flask backend and a modern HTML/CSS frontend.

## 🚀 Features
* Spotify Integration: Connects seamlessly with Spotify API to fetch music data and tracks.
* Smart Recommendations: Generates customized song suggestions based on user preferences.
* Web Interface: Clean, intuitive, and responsive UI built with HTML5 and CSS3.

## 🛠️ Tech Stack
* Backend: Python, Flask
* Frontend: HTML5, CSS3, JavaScript
* APIs: Spotify Web API

## 🔧 Setup & Installation
1. Clone the repository:
git clone https://github.com/coffefreezer/MusicAI.git

2. Install dependencies:
pip install -r requirements.txt

3. Configure your Spotify API credentials in a .env file:
SPOTIFY_CLIENT_ID=your_client_id
SPOTIFY_CLIENT_SECRET=your_client_secret

4. Run the app:
python app.py

Note: The .env file is used to store API keys securely. Make sure to create one and insert your personal API credentials for Spotify and Google Studio before running the app.
